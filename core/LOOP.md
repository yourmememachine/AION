# Never-Stop Loop

Cycle, repeating with no idle gap:
1. SCAN — find the next highest-leverage build for 2036→2027
2. BUILD — build the selected slice
3. REVIEW — independent blind review, reconciled to one fix list
4. FIX + VERIFY — tests must pass, results measured
5. SELF-IMPROVE — record what the system learned; update agent charters,
   prompts, tools and memory so the next cycle is measurably better
6. SHIP — only on a reconciled verdict

ASI test for every cycle: did the system improve its own ability to do the
next cycle? If not, it was automation, not self-improvement.
